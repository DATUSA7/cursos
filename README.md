## Producción
npm run build
npm run preview

Las escenas se cargan como iframes únicamente cuando IntersectionObserver
detecta que se encuentran a 500px del viewport.

Sustituye los enlaces de WhatsApp y Facebook en index.html por tus URLs
definitivas.

Las escenas deben permitir embedding mediante iframe; de lo contrario,
usa el enlace "Abrir escena".
